Built for Technical Presentations

Eliminate re-recordings, mismatched voiceovers, and tedious video editing. Treat video like compiled code.

📝

Presentation as Code

Write standard Quarto Reveal.js or Markdown decks. Code chunks, formulas, and diagrams update your video automatically upon commit.

⚡

Zero Cumulative Drift

Decodes voice to 48 kHz uncompressed PCM. Video frames round on cumulative sample boundaries so audio and slides stay locked to the exact frame.

🎙️

Multi-Engine Neural Voices

Pluggable TTS strategy supporting OpenAI, ElevenLabs, Azure Speech, Amazon Polly, Kokoro (offline neural), and Sarvam AI for Indic languages.

🎛️

Broadcast-Grade Audio

Two-pass EBU R128 loudness normalization (-16 LUFS integrated, -1.5 dBTP) built directly into the assembly pipeline.

💬

Synchronized Subtitles

Automated WebVTT and SubRip (.srt) generation matching exact narration timings, with optional burned-in caption rendering.

🖥️

CLI & Upcoming Studio GUI

Pure CLI compiler for CI/CD automation and scripts, paired with a visual desktop studio coming for educators and content creators.
